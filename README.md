# KimSooHuan App PWA

GitHub Pages ready PWA.

## Upload instructions
1. Extract this ZIP.
2. Upload all extracted files to the root of your GitHub repository.
3. Make sure `index.html`, `manifest.json`, `service-worker.js`, and the icons are in the root folder.
4. Turn on GitHub Pages using the `main` branch and `/root` folder.

## Included
- Inventory Form
- Chè Formula, including Chè Thái
- Money Calculator with $2 bill, Zelle-style revenue input, status row, and PDF export
- Offline PWA support
